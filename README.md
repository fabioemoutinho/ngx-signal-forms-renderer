# ngx-signal-forms-renderer

Render Angular Signal Forms from a declarative layout.

**[📖 Documentation](./projects/ngx-signal-forms-renderer/README.md)** ·
**[🚀 Live demo](https://fabioemoutinho.github.io/ngx-signal-forms-renderer)** ·
**[📦 npm](https://www.npmjs.com/package/ngx-signal-forms-renderer)**

This is the Angular workspace for the library and its demo:

- **`projects/ngx-signal-forms-renderer`** — the published library. Its
  [README](./projects/ngx-signal-forms-renderer/README.md) is the full documentation (and the npm page).
- **`projects/demo`** — the demo app behind the live site.

## Development

```bash
npm install

# Build the library
npx ng build ngx-signal-forms-renderer

# Run the demo app
npx ng serve

# Run the library tests
npx ng test ngx-signal-forms-renderer
```
